Hard rules

Media Always 1:1 in grid, 4:3 in list. Second image swaps on hover only where a pointer exists (@media (hover:hover)) — never on touch. Text never overlaps the badge column.
Title Clamped to 2 lines in standard, 3 in feature. Full title is in the title attribute and in the accessible name, so nothing is lost to the ellipsis.
Price Tabular figures, always the storefront currency of the moment. A strikethrough price renders only when it is a real previous price, never an invented anchor.
Availability Three levels only: in stock, low stock with the exact count and a bar, out of stock with a notify form. Colour is never the only signal — the words carry it.
Variants Max 5 swatches then +N. Sizes render as a chip row; unavailable combinations are struck through, not hidden, so the shopper knows the full range exists.
Tap targets Primary button 44px, secondary 38px, favourite 36px. Card body is clickable, but the button stays a real button for keyboard and screen-reader users.
Equal height Cards in one row share height. The CTA is the last slot and is pinned with margin-top:auto, so nothing sits below it — the button lands on one line in every row whatever the title length, stock state or metadata width happens to be. The availability slot keeps a reserved height (--avail-h) so the info band stays uniform too.
Theming No card rule uses a literal colour. Twenty storefronts ship twenty token blocks and zero CSS forks. Try the brand switcher in the toolbar above.
